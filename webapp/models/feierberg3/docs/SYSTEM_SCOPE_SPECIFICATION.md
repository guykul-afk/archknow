## 2. רשימת תוצרים ומודולים בתיקיית `מודל/`
1. **`index.html` / `feierberg3_3d_bim_viewer.html` / `feierberg3_3d_model.html`**:
   - פורטל תלת-ממד אינטראקטיבי עצמאי (Zero-Dependency Single-File WebGL App) הכולל את כל 14 הקומות, 4 החזיתות, קטלוג 18 הדירות, סיור פנים מרוהט 3D בגוף ראשון, סימולטור נוף מהמרפסת, מד טווח לייזר תלת-ממדי, מחולל הצעות מחיר PDF, ומפת לוויין תלת-ממדית (Triple-Resolution Google Maps Z15/Z17/Z19).
2. **`feierberg3_spatial_map.html`**:
   - מערכת GIS מרחבית אינטראקטיבית עם 28 מוקדי עניין מאומתים בפתח תקווה (בתי ספר, גני ילדים, תחנת מטרו M2 מתוכננת, הקו האדום של הדנקל, בית חולים השרון, מרכזי קניות ופארקים) ו-8 מעגלי מרחק וזמני הליכה.
3. **`feierberg3_model.glb` / `feierberg3_model.obj` / `feierberg3_model.mtl`**:
   - קובצי מודל תלת-ממדי הנדסיים תקניים בקנה מידה מטרי 1:1 (glTF 2.0 Binary ו-Wavefront OBJ/MTL) לייבוא ישיר ל-Revit, SketchUp, Blender, AutoCAD ו-3ds Max.
4. **`compact_bim.json` (בשורש וב-`data/`)**:
   - קובץ אימות הנדסי (Zero-Trust BIM Validation) המאמת רציפות אנכית של גרעין המדרגות והמעלית (`IoU = 1.000`), סכום גבהים אנכי (`Z Error = 0.00m`), קווי בניין, טופולוגיה נקייה ואימות מול 4 החזיתות.
5. **תיקיית `data/`**:
   - `feierberg3_extracted_plans.json` — גיאומטריה וקטורית 1:1 של כל הקומות, הקירות, הפתחים, המרפסות, הפרגולות והריהוט.
   - `feierberg3_units_crm.json` — מסד נתוני ה-CRM של כל 18 הדירות ו-19 החניות.
   - `unified_feierberg3_3d_map.json` ו-`feierberg3_spatial_map_data.json` — שכבות ה-GIS ומפות הלוויין.
6. **תיקיית `src/`**:
   - `export_feierberg3_json.py`, `export_feierberg3_3d_files.py`, `build_feierberg3_gis.py`, `build_feierberg3_viewer.py`, `build_feierberg3_docs.py`.
