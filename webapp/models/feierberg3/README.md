# פאירברג 3, פתח תקווה — פורטל BIM 3D, CRM ומערכת GIS מרחבית

ברוכים הבאים למערכת ההדמיה התלת-ממדית ההנדסית והשיווקית של פרויקט **פאירברג 3, פתח תקווה** (`גוש 6387, חלקה 193`) מבית **א. קולסקי**.

## קבצים ראשיים להפעלה מיידית (ללא צורך בהתקנה או שרת)
- **[`index.html`](file:///g:/תיקיות%20אחסון%20שיתופי/פרויקטים%20שוטפים/פרויקטים%20בביצוע/פאירברג%203/מודל/index.html)** (וכן `feierberg3_3d_bim_viewer.html` / `feierberg3_3d_model.html`):
  פתחו בכל דפדפן לצפייה במודל ה-BIM התלת-ממדי המלא (14 קומות), סיור פנים מרוהט בגוף ראשון, קטלוג 18 הדירות, הפקת הצעות מחיר PDF, חתכי Dollhouse ומפת לוויין תלת-ממדית.
- **[`feierberg3_spatial_map.html`](file:///g:/תיקיות%20אחסון%20שיתופי/פרויקטים%20שוטפים/פרויקטים%20בביצוע/פאירברג%203/מודל/feierberg3_spatial_map.html)**:
  מפת GIS אינטראקטיבית של סביבת הפרויקט בפתח תקווה עם 28 מוקדי עניין מאומתים ורדיוסי הליכה.
- **[`feierberg3_model.glb`](file:///g:/תיקיות%20אחסון%20שיתופי/פרויקטים%20שוטפים/פרויקטים%20בביצוע/פאירברג%203/מודל/feierberg3_model.glb)** ו-**[`feierberg3_model.obj`](file:///g:/תיקיות%20אחסון%20שיתופי/פרויקטים%20שוטפים/פרויקטים%20בביצוע/פאירברג%203/מודל/feierberg3_model.obj)**:
  קבצי תלת-ממד הנדסיים בקנה מידה 1:1 (מטרים) לייבוא לתוכנות תלת-ממד ו-BIM.

## בנייה מחדש של המודל מקובצי המקור (Python)
```bash
python src/export_feierberg3_json.py
python src/export_feierberg3_3d_files.py
python src/build_feierberg3_gis.py
python src/build_feierberg3_viewer.py
```
