# משה שרת 26–28, פתח תקווה — מערכת BIM תלת-ממדית, GIS וקטלוג שיווק (1:100 CAD)

מערכת הדמיה אדריכלית תלת-ממדית (`Three.js r128`), ניתוח מרחבי (`Google Maps 3D/2D GIS`) וניהול מלאי דירות וחניות עבור פרויקט **משה שרת 26–28, פתח תקווה** (גוש 6372, חלקה 1025, מגרש 1025), מבוססת במיפוי וקטורי `1:1` על קובץ ההגשה הרשמי `6.5.26-hagasha.dwfx`.

## קבצים ראשיים להפעלה מיידית (ללא תלות בשרת חיצוני)
* **`sharett26_28_3d_bim_viewer.html`** (וגם **`sharett26_28_3d_model.html`** / **`index.html`**):
  המערכת התלת-ממדית המלאה (14 מפלסים: מרתפים `-2` ו-`-1`, קרקע, גלריה, קומות `1–8`, קומה `9` יציאה לגג וגג עליון, 66 יח"ד ב-2 כניסות ו-70 חניות).
* **`sharett26_28_spatial_map.html`**:
  מפת סביבה ונגישות דו-ממדית אינטראקטיבית של פתח תקווה סביב משה שרת 26–28.
* **`sharett26_28_model.glb`** | **`sharett26_28_model.obj`** | **`sharett26_28_model.mtl`**:
  קבצי מודל תלת-ממדי סטנדרטיים לייבוא לתוכנות תלת-ממד ו-BIM (Blender, SketchUp, Rhino, Revit, 3ds Max).
* **`SYSTEM_SCOPE_SPECIFICATION.md`**:
  מסמך איפיון מלא ופרוגרמת השטחים והמפלסים מהגרמושקה.
