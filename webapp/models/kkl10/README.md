# פרויקט קק"ל 10, פתח תקווה — מודל אדריכלי תלת-ממדי ו-BIM (גרסה v6.1)

פרויקט זה מכיל את המודל האדריכלי המלא (מעטפת חיצונית, חלוקת דירות פנימית, חניונים תת-קרקעיים, מפלסי גגות) בפורמט BIM תלת-ממדי בקנה מידה מדויק 1:1 במטרים. המודל מבוסס על ניתוח מעמיק והצלבה של תוכניות ההגשה (גרמושקה — אדר' אייל סנדרוביץ') ותוכניות המכר בקנה מידה 1:50.

## 📂 מבנה הקבצים בפרויקט

| קובץ | תיאור וייעוד |
| :--- | :--- |
| **`kkl10_3d_bim_viewer.html`** | **ממשק הצפייה האינטראקטיבי הראשי (WebGL / 3D Viewer)** — נפתח ישירות בכל דפדפן (ללא תלות בתוכנה חיצונית). כולל סרגל שכבות BIM, סליידרים לחיתוך חתכים 1-1 ו-2-2, מעבר בלחיצה לכל תוכנית קומה (Plan View), כיתוב מידות חדרים על הרצפה וייצוא נתונים. |

| **`kkl10_threejs_bim_v6_1.js`** | **קובץ נתוני Three.js פרוצדורלי (.js)** — מערכי נתונים לייבוא ישיר במנועי WebGL. |

| **`architectural_extraction_report.md`** | **דוח חילוץ נתונים אדריכלי ומפלסים** — מפרט מלא של כל הגבהים, המפלסים, החתכים, חישובי שטחים והשוואת גרמושקה מול מכר. |

## 🚀 הפעלה וצפייה מקומית ומרחוק

1. **צפייה מקומית ישירה:**
   - לחיצה כפולה על הקובץ `kkl10_3d_bim_viewer.html` תפתח את המודל בדפדפן (Chrome / Edge / Firefox / Safari).
2. **הפעלת שרת מקומי (HTTP Server):**
   ```bash
   python -m http.server 8085
   ```
   ואז פתיחה בדפדפן בכתובת: `http://localhost:8085/kkl10_3d_bim_viewer.html`.
