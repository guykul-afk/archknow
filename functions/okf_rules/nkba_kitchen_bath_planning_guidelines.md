# הנדסת מטבחים וחדרי רחצה — הנחיות NKBA (תת-קבוצה כמותית)

**מקור**: National Kitchen & Bath Association (NKBA), *Kitchen & Bath Planning Guidelines with Access Standards* (ארה"ב/קנדה).
ההנחיות הן הסטנדרט המקצועי המקובל בצפון אמריקה לתכנון ארגונומי של מטבחים וחדרי רחצה. הן משלימות את Neufert (`N.*`) ואת פרק 2 ב-[ISRAEL_2026](israel_housing_planning_book_2026.md), שם הערכים מנוסחים ברמה כללית יותר.

> [!IMPORTANT]
> אלו **הנחיות מקצועיות זרות**, לא חוק ישראלי. המנוע מסמן חריגות כ-`WARN`. בחדרי רחצה מוצגים שני רפים: **Code** (רף מינימלי, מקביל לקוד הבנייה האמריקאי) ו-**Recommended** (רף NKBA המומלץ).

---

## 1. מטבח

### 1.1 משולש העבודה (Work Triangle) — NKBA K-Guideline "Distance Between Work Centers"
- המשולש מחבר את מרכז **הכיור הראשי**, **משטח הבישול** ו**המקרר**.
- **סכום שלוש הצלעות ≤ 7.92 מ'** (26 ft).
- **כל צלע בין 1.22 מ' ל-2.74 מ'** (4–9 ft).
- אסור שציר תנועה ראשי יחצה את המשולש.
- אי מטבח שחוצה צלע של המשולש מקטין אותה ב-30 ס"מ לכל היותר.

### 1.2 מעברים
| מעבר | מינימום |
| :--- | :---: |
| מעבר עבודה — בשלן יחיד (בין משטח לאי / משטח נגדי) | **107 ס"מ** (42") |
| מעבר עבודה — שני בשלנים ומעלה | **122 ס"מ** (48") |
| מעבר הליכה (Walkway) שאינו מעבר עבודה | **91 ס"מ** (36") |
| פתח כניסה למטבח (רוחב פנוי) | **81 ס"מ** (32") |

### 1.3 מרווחים מאחורי אזור ישיבה (אי / שולחן)
| מצב | מרחק משפת השולחן לקיר/מכשול |
| :--- | :---: |
| אין תנועה מאחורי הסועד | **81 ס"מ** (32") |
| מעבר "בצד" (Edge past) | **91 ס"מ** (36") |
| מעבר הליכה מאחורי הסועד | **112 ס"מ** (44") |

### 1.4 משטחי הנחה (Landing Areas)
- **כיור ראשי**: ≥ 61 ס"מ בצד אחד ו-≥ 46 ס"מ בצד השני (24" / 18").
- **כיריים**: ≥ 30 ס"מ בצד אחד ו-≥ 38 ס"מ בצד השני (12" / 15").
- **מקרר**: ≥ 38 ס"מ בצד הידית (15"), או משטח נגדי במרחק ≤ 122 ס"מ.
- **מדיח**: בטווח ≤ 91 ס"מ משפת הכיור.
- **סך חזית משטחי עבודה**: ≥ **401 ס"מ** (158") בעומק 61 ס"מ, עם ≥ 38 ס"מ פנויים מעליו.

### 1.5 עקרונות איכותניים
- דלת כניסה לא תתנגש בדלת מכשיר, ודלתות מכשירים לא יתנגשו זו בזו (במיוחד בפינה).
- כיריים לא ימוקמו מתחת לחלון נפתח, ולא בקצה ריצה ללא משטח.

## 3. התאמה לדירה הישראלית
- **פינת אוכל בדירה ישראלית** משמשת לאירוח של 10–14 סועדים בשבתות וחגים. מומלץ לבדוק שהמרווח מאחורי שולחן **מוארך** (ולא רק שולחן היומיום) עומד ב-81–112 ס"מ.
- **אי צר** (עומק < 60 ס"מ) אינו מאפשר ישיבה וגם אינו משמש משטח הנחה מלא — ראו המקרה של דירה C בפינס 48 (אי 56×106 ס"מ).
