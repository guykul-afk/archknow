- **Category**: `Pytest Collection & Legacy Scratch Isolation`
- **Confidence**: `high`

## Cue (Shape of Situation)
Running bare pytest in a repository that contains legacy one-off scripts named test_*.py inside webapp/models/*/src/

## Evidence (Trajectory Failure & Resolution)
- **Observed Failure / Divergence**: pytest.ini created; 77/77 root tests pass cleanly.
- **Applied Fix**: Always configure pytest.ini with norecursedirs = webapp/models .git .firebase __pycache__ functions/node_modules so pytest collects only the root verification suites and does not fail on legacy model-extraction scripts with missing local DXF/PIL dependencies.

## Transferable Lesson
Always configure pytest.ini with norecursedirs = webapp/models .git .firebase __pycache__ functions/node_modules so pytest collects only the root verification suites and does not fail on legacy model-extraction scripts with missing local DXF/PIL dependencies.
