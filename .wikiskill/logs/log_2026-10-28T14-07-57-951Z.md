## Cue (Shape of Situation)
When updating project analysis payloads, 3D overlays, or static JSON exports in a project deployed to Firebase Hosting or using embedded preload scripts

## Evidence (Trajectory Failure & Resolution)
- **Observed Failure / Divergence**: Live site https://archknow-guy-2026.web.app was serving stale 20-note payload until cache-busters and Firebase Hosting were updated
- **Applied Fix**: Always (1) overwrite embedded preload/standalone scripts (e.g., hafetz44_audit_preload.js and hafetz44_audit_3d_standalone.js) in both the central model folder and webapp/models/<pid>/, (2) bump cache-busting query strings (?v=...) on app.js, audit_3d_overlay.js, and static /api/<pid>.json fetches, and (3) deploy to Firebase Hosting and verify the live URL response.
